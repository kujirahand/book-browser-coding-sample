# Appendix4. Go言語のインストールについて

本書の4章では、Go言語を利用したプログラムを紹介します。そこで、Go言語のインストール方法について解説します。OSごとにインストール方法が異なるので、Windows、macOS、Linuxそれぞれの方法を解説します。

## WindowsでGo言語のインストール方法

WindowsでGo言語をインストールする方法は、公式サイトからインストーラーをダウンロードして実行する方法が一般的です。以下の手順でインストールできます。

1. Go言語の公式サイト(https://go.dev/dl/)にアクセスします。
2. Downloadページにて、「Microsoft Windows」を選んでダウンロードします。通常は、64ビット版の「go1.xx.xx.windows-amd64.msi」(xxはバージョン番号)を選びます。
3. ダウンロードしたインストーラーを実行します。
4. インストーラーの指示に従ってインストールを進めます。
5. インストールが完了したら、コマンドプロンプトやPowerShellを開いて、次のコマンドを入力してGo言語が正しくインストールされたか確認します。

```sh
$ go version
```

これで、次の画面のように、Go言語のバージョンが表示されれば、インストールは成功です。

## macOSでGo言語のインストール方法

macOSでGo言語をインストールする方法は、Homebrewを利用する方法が一般的です。以下の手順でインストールできます。

1. Homebrewがインストールされていない場合は、公式サイト(https://brew.sh/)の指示に従ってHomebrewをインストールします。
2. ターミナルを開いて、次のコマンドを入力してGo言語をインストールします。

```sh
$ brew install go
```

3. インストールが完了したら、次のコマンドを入力してGo言語が正しくインストールされたか確認します。

```sh
$ go version
```

これで、Go言語のバージョンが表示されれば、インストールは成功です。

なお、Go言語の公式サイトからインストーラーをダウンロードしてインストールする方法もあります。古いmacOSを利用している場合には、公式のインストーラーが安定するようです。その場合、公式サイトのDownloadページで「macOS」を選んで、適切なインストーラーをダウンロードして実行してください。

## LinuxでGo言語のインストール方法

LinuxでGo言語をインストールする方法は、ディストリビューションによって異なりますが、一般的にはパッケージマネージャーを利用する方法が推奨されます。以下は、Ubuntuを例にした手順です。

1. ターミナルを開いて、次のコマンドを入力してGo言語をインストールします。

```sh
$ sudo apt update
$ sudo apt install golang-go
```
2. インストールが完了したら、次のコマンドを入力してGo言語が正しくインストールされたか確認します。

```sh
$ go version
```

これで、Go言語のバージョンが表示されれば、インストールは成功です。
