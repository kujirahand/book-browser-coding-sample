# Appendix3 Node.jsのインストールについて

本書の4章では、Node.jsを利用したプログラムを紹介します。そこで、Node.jsのインストール方法について解説します。なお、Node.jsは、JavaScriptの実行環境で、これをインストールすることで、JavaScriptをブラウザ以外の環境でも実行できるようになります。OSごとにインストール方法が異なるので、Windows、macOS、Linuxそれぞれの方法を解説します。

## WindowsでNode.jsのインストール方法

WindowsでNode.jsをインストールする方法は、公式サイトからインストーラーをダウンロードして実行する方法が一般的です。以下の手順でインストールできます。

1. Node.jsの公式サイト(https://nodejs.org/)にアクセスします。
2. Downloadページにて、「LTS」(Long Term Support)バージョンを選択して、「Windows Installer (.msi)」を選んでダウンロードします。LTSバージョンは、安定していて長期間サポートされるバージョンです。
3. ダウンロードしたインストーラーを実行します。
4. インストーラーの指示に従ってインストールを進めます。特に、迷うところはないのですが、Node.jsをPATH環境変数に追加するオプション(Add to PATH)をオンの状態にしておきましょう。これにより、コマンドプロンプトやPowerShellからNode.jsを簡単に実行できるようになります。
5. インストールが完了したら、コマンドプロンプトやPowerShellを開いて、次のコマンドを入力してNode.jsが正しくインストールされたか確認します。

```sh
$ node -v
```

これで、Node.jsのバージョンが表示されれば、インストールは成功です。

## macOSでNode.jsのインストール方法

macOSでNode.jsをインストールする方法は、Homebrewを利用する方法が一般的です。以下の手順でインストールできます。

1. Homebrewがインストールされていない場合は、公式サイト(https://brew.sh/)の指示に従ってHomebrewをインストールします。
2. ターミナルを開いて、次のコマンドを入力してNode.jsをインストールします。

```sh
$ brew install node
```

3. インストールが完了したら、次のコマンドを入力してNode.jsが正しくインストールされたか確認します。

```sh
$ node -v
```

これで、Node.jsのバージョンが表示されれば、インストールは成功です。

## LinuxでNode.jsのインストール方法

LinuxでNode.jsをインストールする方法は、ディストリビューションによって異なりますが、一般的にはパッケージマネージャーを利用する方法が推奨されます。以下は、Ubuntuを例にした手順です。

1. ターミナルを開いて、次のコマンドを入力してNode.jsをインストールします。

```sh
$ sudo apt update
$ sudo apt install nodejs npm
```

2. インストールが完了したら、次のコマンドを入力してNode.jsが正しくインストールされたか確認します。

```sh
$ node -v
```

これで、Node.jsのバージョンが表示されれば、インストールは成功です。

以上が、Windows、macOS、LinuxでNode.jsをインストールする方法です。インストールが完了したら、Node.jsを利用したプログラムを実行できるようになります。
